# 围棋死活题/学棋产品竞品调研报告

> 调研日期：2026年5月27日
> 调研背景：为 go-daily（围棋死活题学习产品）提供竞争格局分析

---

## 一、各产品详细分析

### 1. OGS (Online Go Server) — online-go.com

**基本信息**

- 产品定位：国际最大的免费在线围棋平台之一，提供对弈、教学、死活题一站式服务
- 目标用户：全球围棋爱好者，从初学者到高段位
- 平台：Web（主要），响应式设计适配移动端
- 用户量级：数十万注册用户，峰值并发数百至数千人
- 开源状态：GitHub 1515 星、393 fork，TypeScript，活跃维护中

**功能分析**

- 核心功能：实时/通信制对弈、Glicko-2 等级分系统、AI 对手、棋谱分析、定石探索器
- 死活题系统：有 puzzle 功能但不是核心卖点；题库来自社区贡献，分级不够精细
- AI 辅助：内置 AI 复盘分析（支持 KataGo 集成）
- 社交功能：论坛、游戏回顾、好友系统、教学直播
- 学习路径：无系统化课程体系

**变现模式**：完全免费，通过捐赠维持运营，无广告

**用户评价**

- 好评：完全免费、功能全面、社区活跃、开源透明
- 差评：UI 界面较朴素、死活题功能偏弱、移动端体验不如原生 App

---

### 2. Tsumego Pro — 日本棋院出品

**基本信息**

- 产品定位：专业围棋死活题训练 App，日本棋院背书
- 目标用户：认真学习围棋死活的各级别棋手
- 平台：iOS / Android
- 用户量级：Google Play 百万级下载

**功能分析**

- 核心功能：海量死活题库，按段级位分级（30级~7段+）
- 死活题系统：题库来自日本棋院权威题库，分级精确，支持计时模式、重复练习、间隔重复算法（SRS）
- AI 辅助：基础 AI 正解判断，无深度分析
- 社交功能：无
- 学习路径：按难度循序渐进，无结构化课程

**变现模式**：免费版含广告和有限题目；付费版一次性购买约 $3-5，解锁全部题库

**用户评价**（评分 4.5+）

- 好评：题库质量高、界面简洁、做题体验流畅、SRS 算法
- 差评：部分用户希望更多题目、偶尔 UI 小 bug

---

### 3. BadukPop — 韩国围棋学习 App

**基本信息**

- 产品定位：游戏化的围棋学习和死活题平台
- 目标用户：围棋初学者到中级玩家，特别是韩国市场
- 平台：iOS / Android
- 用户量级：Google Play 百万级下载

**功能分析**

- 核心功能：死活题训练、在线对弈、段位系统、每日挑战
- 死活题系统：题目来自真实对局位置，按难度分级；支持计时模式、排行榜竞技
- 社交功能：好友挑战、排行榜、竞技元素
- 学习路径：游戏化进度系统

**变现模式**：免费下载 + 应用内购买，有广告

**用户评价**（评分 4.0-4.5）

- 好评：游戏化体验有趣、题目来自真实对局、界面现代
- 差评：广告较多、部分功能需付费、高级内容受限

---

### 4. 弈客围棋 — 国内主流围棋 App

**基本信息**

- 产品定位：国内最全面的围棋综合平台
- 目标用户：中国围棋爱好者全谱系
- 平台：iOS / Android / Web
- 用户量级：千万级注册用户，国内头部

**功能分析**

- 核心功能：在线对弈、AI 对弈、死活题、棋谱库、赛事直播、教学课程
- 死活题系统：题库丰富，支持多种题型（死活、手筋、布局、官子）
- AI 辅助：深度集成 AI（KataGo），AI 复盘分析、AI 推荐手
- 社交功能：社区讨论、棋友圈、赛事组织
- 学习路径：有系统课程体系

**变现模式**：基础免费 + 会员订阅制（月/年），部分课程单独付费，有广告

**用户评价**（评分 4.0-4.5）

- 好评：功能全面、社区活跃、题库丰富、AI 分析强大
- 差评：广告多、部分功能收费偏贵、偶有服务器问题

### 5. 野狐围棋 (Fox Weiqi)

**基本信息**

- 产品定位：国内高端在线对弈平台，以高水平对局著称
- 目标用户：中高水平围棋爱好者、职业棋手
- 平台：PC 客户端 / Web / iOS / Android
- 用户量级：数百万注册用户

**功能分析**

- 核心功能：在线对弈（高水平对局闻名）、AI 对弈、棋谱分析
- 死活题功能弱，非核心

**变现模式**：基础免费 + VIP 会员制，有广告

**用户评价**

- 好评：对弈质量高、职业棋手活跃、段位含金量高
- 差评：界面传统、死活题功能弱、新用户门槛高

### 6. 101围棋网 — 101weiqi.com

**基本信息**

- 产品定位：国内专业围棋死活题在线平台
- 目标用户：各级别围棋学习者
- 平台：Web
- 用户量级：估计数十万注册用户

**功能分析**

- 核心功能：海量死活题库（数十万题）、死活题擂台、布局题、手筋题
- 死活题系统：按难度分为入门/初级/中级/高级，支持社区提交正解图/失败图
- 社交功能：死活题擂台、社区审题

**变现模式**：免费使用

**用户评价**

- 好评：题库海量、免费、专业性强
- 差评：界面朴素、仅 Web 端

- 定位：移动端快速围棋对弈，专注 9x9 和 13x13 小棋盘
- 无死活题功能，无深度学习功能

### 8. SmartGo Kifu

- 定位：专业围棋棋谱数据库和学习工具
- 平台：iOS / macOS
- 一次性付费约 $10-30，棋谱库权威全面
- 死活题非核心功能

### 9. 黑猫围棋

- 国内围棋学习 App，面向初中级爱好者
- 功能不如弈客全面，用户基数较小

## 三、关键发现

### 1. 市场空白与机会

**死活题垂直赛道缺乏"精品+现代"产品**：

- Tsumego Pro 是死活题标杆，但功能单一、无社交、无 AI 深度分析
- 101围棋题库海量，但仅 Web 端、界面老旧
- 弈客围棋功能全面但臃肿，死活题不是核心，广告多
- **没有一款产品同时做到：精品死活题 + 现代 UI + AI 辅助 + 轻量社交 + 良好移动端体验**

### 2. 用户痛点

- **广告干扰**：BadukPop、弈客围棋免费版广告多，影响体验
- **题库质量参差不齐**：社区贡献的题目需要审核机制
- **缺乏个性化学习路径**：大多数产品只有简单难度分级，无个性化推荐
- **AI 分析与死活题割裂**：对弈平台的 AI 分析和死活题训练是分离的
- **移动端体验不足**：101围棋等专业平台缺乏原生移动端

### 3. 变现模式趋势

- 一次性付费在死活题领域接受度高（Tsumego Pro 模式）
- 订阅制在综合平台更常见（弈客围棋模式）
- 免费增值（Freemium）是主流策略
- 广告是双刃剑：带来收入但损害体验

### 4. 技术趋势

- AI 集成已成标配：KataGo 等开源引擎的集成
- 游戏化设计能有效提升用户粘性（BadukPop 模式）
- 间隔重复算法（SRS）在死活题训练中效果显著
- WebAssembly 在 Web 端围棋应用中提升性能（OGS 模式）

## 四、对 go-daily 的启示与建议

### 产品定位建议

**"精品死活题 + AI 个性化 + 现代体验"**

瞄准 Tsumego Pro 和 101围棋之间的市场空白：既有专业级的死活题体验，又有现代 AI 辅助和移动端优先的设计。

### 核心差异化方向

1. **AI 驱动的个性化学习路径** — 根据用户做题数据动态调整难度，分析薄弱环节，推荐针对性题目。这是目前所有竞品都没做好的点。
2. **移动端优先的精品体验** — Tsumego Pro 的做题体验 + 现代 UI 设计，碎片化时间友好（每日一题、快速训练模式）。
3. **轻量社交 + 激励机制** — 学习排行榜、每日打卡、成就系统，参考 BadukPop 的游戏化设计但更克制。
4. **题库质量保障** — 社区审核机制（参考 101围棋），专业来源题库 + AI 辅助出题。

### 变现策略建议

- **基础免费 + 高级订阅**：每日免费 N 题，订阅解锁无限题库 + AI 分析
- **一次性购买选项**：参考 Tsumego Pro，提供永久解锁选项
- **避免过度广告**：这是用户最大痛点

### 优先级建议

1. **MVP 阶段**：精品死活题体验 + 基础难度分级 + 每日训练模式
2. **增长阶段**：AI 个性化推荐 + 社交功能 + 游戏化
3. **变现阶段**：订阅制 + 高级 AI 功能
